# centre.F90

## 功能概述
输出格式化辅助子程序。将字符串居中显示在输出文件顶部，带有星号边框。

## 主要子程序/函数

| 名称 | 功能 |
|------|------|
| `CENTRE` | 字符串居中输出 |

## 输出格式
```
******************************************************************************************************************************
*                                              STRING内容                                                        *
******************************************************************************************************************************
```

## 参数
| 参数 | 说明 |
|------|------|
| `NB` | 输出单元号 |
| `STRING` | 要居中的字符串 |

## 算法
1. 计算字符串实际长度（去除尾部空格）
2. 计算居中起始位置 `I1 = (126 - LENGTH) / 2`
3. 构造 126 字符宽的行，首尾填充 '*'

## 使用场景
在程序开始或章节标题处输出分隔线。
