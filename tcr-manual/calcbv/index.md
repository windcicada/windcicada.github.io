# Calcbv

# Calcbv.F90

## 功能概述
根据给定的速度分量（法向、切向1、切向2）计算直角坐标系下的速度分量 (u, v, w)。

## 主要子程序/函数

| 名称 | 功能 |
|------|------|
| `Calcbv` | 速度坐标系转换 |

## 算法描述

### 输入
| 参数 | 说明 |
|------|------|
| `v1` | 法向速度分量 |
| `v2` | 切向1速度分量 |
| `v3` | 切向2速度分量 |

### 输出
| 参数 | 说明 |
|------|------|
| `u` | X方向速度 |
| `v` | Y方向速度 |
| `w` | Z方向速度 |

### 坐标变换
使用法向量 (nx, ny, nz)、切向向量 (sx, sy, sz) 和 (tx, ty, tz) 构造变换矩阵：
```
[ nx ny nz ]   [ u ]   [ v1 ]
[ sx sy sz ] * [ v ] = [ v2 ]
[ tx ty tz ]   [ w ]   [ v3 ]
```

调用 `linsol` 求解线性方程组得到 u, v, w。

## 依赖模块
- `extras`：法向量变量 (nx, ny, nz, sx, sy, sz, tx, ty, tz)
