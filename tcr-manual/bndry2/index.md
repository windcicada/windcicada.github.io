# BNDRY2.F90 - 标量边界条件子程序

## 功能概述

`BNDRY2` 是 TCR 求解器中的标量边界条件处理子程序，负责在六个物理边界面对标量场（如密度、温度、混合分数、焓等）应用相应的边界条件。

## 调用关系

```
boffin.F90 → BNDRY2(u,v,w)
```

## 边界类型定义

| 标记值 | 边界类型 | 说明 |
|--------|----------|------|
| `0` | 周期性条件 | 周期边界 |
| `-1` | 入口 (Inflow) | 指定密度 |
| `-10` | 特征边界 - 密度 | 基于特征理论的密度边界 |
| `-12` | 特征边界 - 温度 | 基于特征理论的温度边界 |
| `-14` | 滞止压力与焓边界 | 滞止点边界条件 |
| `-2` | 出口 (Outflow) | 零梯度 |
| `-3` | 对称 (Symmetry) | 对称/自由滑移 |
| `-4` | 壁面 - Dirichlet | 标量 Dirichlet + 速度壁函数 |
| `-40` | 壁面 - Dirichlet (无壁函数) | 标量 Dirichlet |
| `-5` | 壁面 - Neumann | 标量 Neumann + 速度壁函数 |
| `-50` | 壁面 - Neumann (无壁函数) | 标量 Neumann |
| `-6` | 常压卷吸边界 | 恒压卷吸 |
| `-60` | 特征边界 - 压力 | 基于特征理论的压力边界 |

## 算法说明

### 边界循环

程序在三个方向各调用两次 `BOUNDARY2` 子程序（正向和反向）：

```
i 方向: i=2 (左边界), i=l (右边界)
j 方向: j=2 (下边界), j=m (上边界)  
k 方向: k=2 (底边界), k=n (顶边界)
```

### 参数传递

```fortran
call BOUNDARY2(i, sc, ibs, fsth, m, n,   &
                io(2), imax, io,         &
                jo(2), jmax, jo,         &
                ko(2), kmax, ko, u, v, w)
```

- `sc/nc`: 系数数组索引（西/北）
- `ibs/ibw/ibl/ibn/ibe/ibr`: 边界标记数组
- `fsth/fwst/flft/fnth/fest/frht`: 边界值数组
