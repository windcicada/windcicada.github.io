cgstab

CGSTAB.F90 - Bi-CGSTAB 求解器

功能概述

CGSTAB 是 TCR 求解器中用于求解 动量方程 的 双共轭梯度稳定化 (Bi-CGSTAB) 求解器。该算法由 Van der Vorst (1990) 提出，适用于非对称线性方程组，比标准 CG 方法具有更平滑的收敛特性。

算法参数

参数 说明
预处理器 ILU (不完全 LU 分解)
收敛条件 error > tol(nv)
最大迭代 icycl(nv)
向量化 可选对角预处理器

Bi-CGSTAB 算法

Bi-CGSTAB 结合了共轭梯度 (CG) 和双共轭梯度 (Bi-CG) 的优点，通过稳定化机制避免 Bi-CG 的不规则收敛。

ρ_k = r₀ · r_{k-1}
β_k = (ρ_k / ρ_{k-1}) * (α_{k-1} / ω_{k-1})
p_k = r_{k-1} + β_k * (p_{k-1} - ω_{k-1} * v_{k-1})

s = M^{-1} p_k          (预处理器求解)
v = A s                 (矩阵-向量乘)
α = ρ_k / (r₀ · v)

x_k = x_{k-1} + α * s
r_k = r_{k-1} - α * v

t = M^{-1} r_k          (预处理器求解)
ω_k = (t · r_k) / (t · t)

x_k = x_k + ω_k * t
r_k = r_k - ω_k * t

初始化: r = b - Ax, r₀ = r, p = r

while (error > tol 且 iter < max_iter)
    1. 计算 ρ = r₀ · r
    2. 计算 β
    3. 更新搜索方向 p = r + β*(p - ω*v)
    4. 预处理求解: s = M^{-1} * p
    5. 矩阵-向量乘: v = A * s
    6. 计算步长 α = ρ / (r₀ · v)
    7. 更新解: x = x + α * s
    8. 更新残差: r = r - α * v
    9. 预处理求解: t = M^{-1} * r
    10. 计算 ω = (t · r) / (t · t)
    11. 更新解: x = x + ω * t
    12. 更新残差: r = r - ω * t
    13. 检查收敛

与 CGSOL 的对比

特性 CGSTAB CGSOL
算法 Bi-CGSTAB + ILU PCG + ICCG
矩阵要求 非对称 对称正定
用途 动量方程 压力方程
工作数组 7 个 4 个
收敛稳定性 平滑 依赖矩阵性质

性能特点

  • 内存: 7 个额外工作数组
  • 通信: 每次迭代多次 MPI 归约
  • 适用: 速度场求解（对称/非对称矩阵）

备选方案

  1. 对角预处理器: 替代 ILU，简化但收敛略慢
  2. L-D-U 截断展开: Van der Vorst 提出的向量化方案
