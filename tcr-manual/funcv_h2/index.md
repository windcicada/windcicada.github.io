## 功能概述
**9 物种氢气 (H₂) 燃烧化学动力学机理**。包含 19 个反应，覆盖 H₂/O₂ 燃烧的完整基元反应路径。

## 子程序接口
```fortran
subroutine funcv_h2(nsp, yn, fvec, den, temp, p, iopt)
```

## 关键反应 (19 步)
1. `O₂ + H = OH + O`
2. `H₂ + O = OH + H`
3. `H₂ + OH = H₂O + H`
4. `OH + OH = H₂O + O`
5. `H₂ + M = H + H + M` (链引发)
6. `O + O + M = O₂ + M`
7. `O + H + M = OH + M`
8. `H + OH + M = H₂O + M`
9. `H + O₂ + M = HO₂ + M`
10. `HO₂ + H = OH + OH`
11. `HO₂ + H = H₂ + O₂`
12. `HO₂ + OH = H₂O + O₂`
13. `H₂O₂ + H = H₂ + HO₂`
14. `H₂O₂ + OH = H₂O + HO₂`
15. `HO₂ + HO₂ = H₂O₂ + O₂`
... 等
