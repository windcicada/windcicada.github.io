# boundary_edge.F90

## 功能概述
计算网格边缘（edge）和角点（corner）处的变量值。使用距离加权平均方法，根据相邻内点的值插值得到边界边缘值。

## 主要子程序/函数

| 名称 | 功能 |
|------|------|
| `boundary_edge` | 边缘/角点插值 |

## 算法描述

### 1. 距离加权平均
对于边缘点（两个方向边界交线）：
```fortran
f(ijk) = (s1*f(ijke) + s2*f(ijkn)) / (s1 + s2)
```
其中 s1, s2 是到相邻内点的距离。

### 2. 角点处理
对于角点（三个方向边界交点）：
```fortran
f(ijk) = 0.5 * ((s1+s2)*f(ijkr) + (s1+s3)*f(ijke) + (s2+s3)*f(ijkn)) / (s1+s2+s3)
```

### 3. 跳过条件
如果边界标记为 -100（内部点），则跳过处理。

## 关键参数
| 参数 | 说明 |
|------|------|
| `ibs, ibw` | 边界标记数组 |
| `iadd, jadd, kadd` | 方向偏移量 |

## 依赖模块
- `arrays`：网格坐标 (X, Y, Z)
- `global`：上下限、输出单元
