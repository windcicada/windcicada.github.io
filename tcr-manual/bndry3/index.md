# BNDRY3.F90 - 速度分量边界条件子程序

## 功能概述

`BNDRY3` 是 TCR 求解器中处理速度分量 (U, V, W) 边界条件的子程序。与 `BNDRY2` 处理标量不同，`BNDRY3` 专门处理三个速度分量的边界值应用。

## 调用关系

```
boffin.F90 → BNDRY3(u,v,w)
```

## 边界类型定义

| 标记值 | 边界类型 | 说明 |
|--------|----------|------|
| `0` | 周期性条件 | 周期边界 |
| `-1` | 入口 (Inflow) | 指定入口速度 |
| `-2` | 出口 (Outflow) | 零梯度 |
| `-3` | 对称 (Symmetry) | 对称/自由滑移 |
| `-4` | 壁面 - Dirichlet | 无滑移壁面 |
| `-40` | 壁面 - Dirichlet (无壁函数) | 无速度壁函数 |
| `-41` | 对数律壁面 (瞬时) | 瞬时壁面函数 |
| `-42` | 对数律壁面 (平均) | 平均壁面函数 |
| `-5` | 壁面 - Neumann | 零通量壁面 |

## 算法说明

### 边界循环

与 `BNDRY2` 类似，在三个方向各调用两次 `BOUNDARY3`：

```
i 方向: i=2 (左边界, ibs), i=L (右边界, ibn)
j 方向: j=2 (下边界, ibw), j=M (上边界, ibe)
k 方向: k=2 (底边界, ibl), k=N (顶边界, ibr)
```

### 参数传递

```fortran
call BOUNDARY3(i, ibs, fsth, m, n,       &
               io(2), imax, io,          &
               jo(2), jmax, jo, w2,      &
               ko(2), kmax, ko, w3, u, v, w)
```

- `ibs/ibw/ibl/ibn/ibe/ibr`: 边界标记数组
- `w1/w2/w3`: 工作数组（用于边界值计算）
- `u, v, w`: 速度分量数组

### 特殊处理

- **壁面函数**: 当边界标记为 `-41` 或 `-42` 时，使用对数律壁面函数计算壁面速度
- **对称边界**: 使用 `w2` 数组计算法向速度为零的条件

## 与 BNDRY2 的区别

| 特性 | BNDRY2 | BNDRY3 |
|------|--------|--------|
| 处理对象 | 标量 (密度、温度、焓等) | 速度分量 (U, V, W) |
| 子程序 | BOUNDARY2 | BOUNDARY3 |
| 工作数组 | 无额外数组 | w1, w2, w3 |
