COAST v1 / 下载与快速开始

COAST v1 面向 Linux x86_64 高性能计算集群，使用 OpenMPI 与 Slurm 进行并行计算。本次发布提供的是无源码的目标机链接包，以及两个可直接用于验证环境的示例数据包；请先完成完整性校验、目标机链接和验证，再提交正式作业。

⬇️ 前往北航网盘下载 COAST v1

English users: see the English download page and the English Quick Guide.

发布包内容

文件 用途
COAST.v1-SourceFile.tar.gz 无源码目标机链接包；在目标超算完成链接后生成 aecsc。
COAST.v1-FlameD-ExampleData.tar.gz FlameD 示例输入数据，固定使用 192 个 MPI 进程。
COAST.v1-GTMC-ExampleData.tar.gz GTMC 示例输入数据，固定使用 128 个 MPI 进程。
COAST.v1-USER_MANUAL.pdf 完整发布说明。

每个压缩包均应与同名 .sha256 文件一并下载。请完整保留并解压数据包，勿单独复制 case.json、Restart/ 或 boundary_conditions.d 中的文件。

四步开始使用

1. 校验并解压

sha256sum -c COAST.v1-SourceFile.tar.gz.sha256

tar -xzf COAST.v1-SourceFile.tar.gz

tar -xzf COAST.v1-GTMC-ExampleData.tar.gz

.sha256 文件位于压缩包外部，必须和对应 .tar.gz 放在同一目录。

2. 在目标集群完成链接

cd AECSC-D.1-SourceFile-Link
module purge
module load gcc/7.3.0
module load mpi/openmpi/4.1.1-gcc7.3.0

./scripts/target_link.sh
./scripts/target_verify.sh

只有两个脚本均成功退出后才可运行。当前解压目录即安装根目录；请不要混入旧版本的 lib/、registry/、Fuels/、schema/ 或 scripts/。

3. 先进行配置验证

PROJECT=/path/to/project
INSTALL="$PROJECT/AECSC-D.1-SourceFile-Link"
GTMC="$PROJECT/AECSC-D.1-GTMC-ExampleData"
mkdir -p "$PROJECT/runs/gtmc"

"$INSTALL/bin/aecsc" "$GTMC/case.json" --print-resolved > "$PROJECT/runs/gtmc/case.resolved.json"
mpirun -np 128 "$INSTALL/bin/aecsc" "$GTMC/case.json" \
  --validate --output "$PROJECT/runs/gtmc"

--validate 只检查配置、路径和 MPI 进程数，不会推进时间步。FlameD 示例应使用 192 个 MPI 进程。

4. 运行与结果管理

在集群作业环境中加载与目标机链接相同的模块，并设置 LD_LIBRARY_PATH 与 PATH。提交作业时始终使用 "$INSTALL/bin/aecsc" 的绝对路径，输出目录应放在示例输入根目录之外。

使用边界

可修改 case.json 中与研究目标有关的参数，或在个人工作目录中新建 JSON 文件。请保持发布的 boundary_conditions.d、Restart/、Decomp/、mesh_identity.* 以及安装根的 lib/、registry/、Fuels/、schema/、scripts/ 不变。
